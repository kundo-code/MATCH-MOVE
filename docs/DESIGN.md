# MATCH-MOVE 골프 AI 질문 DB & 콘텐츠 갭 자동화 설계

40대~70대 한국 골퍼가 "국가→지역→골프장→패키지→가격→날씨→이동→숙박→식사→후기→
여행사 신뢰→안전→비교→구매" 여정에서 AI/검색엔진에 실제로 물어볼 법한 질문을
DB화하고, 수요 대비 콘텐츠 부재 구간을 매주 자동으로 찾아 블로그·쇼츠 소재로
전환하는 시스템의 설계 문서다.

## 1. 전체 구조

```
[1] 마스터 질문 DB (data/master_questions.csv, 531행)
        │  질문 생성기: scripts/generate_questions.py
        ▼
[2] Google Sheets 마스터 시트 (CSV 임포트)
        │  GADS/ARS 점수 부여, Opportunity 산출
        ▼
[3] 주간 트렌드 로그 (매주 금요일, 수동+반자동 수집)
        │  Apps Script: gas/WeeklyDigest.gs
        ▼
[4] Weekly TOP20 자동 추출 (수요 높음 + 콘텐츠 없음)
        ▼
[5] 콘텐츠 파이프라인 (블로그/쇼츠 기획→제작→발행 트래킹)
```

## 2. 질문 분류 체계 (14 카테고리)

요청하신 여정 순서를 그대로 L1 카테고리로 사용한다. 각 카테고리는
① 목적지(국가-지역)에 결합되는 **원형 템플릿**, ② 연령대(40/50/60/70대) 이슈가
강한 항목에 붙는 **연령대 템플릿**, ③ 목적지 무관 **일반/비교 템플릿** 세 종류로
질문을 생성한다.

| L1 카테고리 | 의미 | 대표 질문 예시 |
|---|---|---|
| 국가 | 국가 단위 관심/타당성 | "베트남 골프여행 요즘 갈만한가요?" |
| 지역 | 지역(다낭/세부 등) 단위 정보 | "다낭 골프투어 비수기는 언제예요?" |
| 골프장 | 코스 난이도/그린피/캐디 | "다낭 골프장 캐디 한국어 가능한가요?" |
| 패키지 | 일정 구성, 라운딩 횟수 | "3박5일 패키지에 라운딩 몇 회 포함되나요?" |
| 가격 | 총비용, 숨은 비용, 최저가 | "4박6일 골프여행 총 비용 얼마나 드나요?" |
| 날씨 | 시즌/체력 대비 날씨 | "우기에도 골프여행 가도 되나요?" |
| 이동 | 항공/공항-골프장 이동, 골프백 규정 | "장시간 비행 무릎 안 좋은데 괜찮을까요?" |
| 숙박 | 호텔 등급, 룸타입, 조식 | "골프텔이랑 리조트 중 뭐가 나아요?" |
| 식사 | 한식/현지식, 식단 조절 | "당뇨 있는데 현지식 괜찮을까요?" |
| 후기 | 실사용 후기, 신뢰도 검증 | "60대 이상 골퍼 후기 어디서 보나요?" |
| 여행사신뢰 | 여행사 검증, 계약/환불 | "여행사 사기 안 당하려면 뭘 확인하나요?" |
| 안전 | 보험, 지병, 응급상황 | "혈압약 챙겨서 가도 안전할까요?" |
| 비교 | 지역·상품·연령대 간 비교 | "베트남과 태국 중 어디가 나을까요?" |
| 구매 | 예약/할인/결제 전환 | "얼리버드 할인은 언제부터 시작하나요?" |

`data/master_questions.csv` 컬럼: `ID, L1_카테고리, 국가, 지역, 연령대, 질문,
GADS, ARS, Opportunity, 콘텐츠상태, 콘텐츠타입후보, 콘텐츠링크, 최종업데이트일,
담당자, 비고`

목적지 풀은 실제 한국 시니어 골프여행 수요가 있는 21개 지역(베트남 5·태국 4·
필리핀 3·중국 1·일본 3·캄보디아 1·말레이시아 1·국내 3)으로 구성했다. 카테고리별로
샘플링하는 목적지 수를 조절해 총량을 500~1000 범위(현재 531행) 안에서 통제한다.
`scripts/generate_questions.py` 의 `DEST_SAMPLE_SIZE`, 각 카테고리 템플릿 리스트를
늘리면 손쉽게 800~1000행까지 확장 가능하다.

## 3. GADS/ARS 점수체계

### GADS (Golf AI Demand Score, 수요 점수 0~100)
"이 질문을 실제 타겟 골퍼가 AI/검색에 물어볼 가능성"을 추정한다.

| 구성요소 | 가중치 | 설명 |
|---|---|---|
| 검색량 추정 (Search Volume Proxy) | 35% | 네이버 데이터랩·구글트렌드·검색광고 키워드플래너 상대값 |
| 시급성/시즌성 (Seasonality) | 20% | 현재 시점(성수기 임박, 환율 이슈 등)과 관련될수록 가중 |
| 구매전환 근접도 (Purchase Intent) | 30% | 가격/비교/구매 카테고리는 실제 상담·예약 직전 질문이라 가중 상향 |
| 연령대 적합성 (Age-fit 40~70) | 15% | 타겟 연령대가 실제로 던질 법한 질문일수록 가중 |

MVP 단계(현재 CSV)에서는 카테고리별 기준점수(`gads_base`, 예: 가격 90·비교 88·
날씨 60)에 목적지 인기도 보정과 질문별 미세 조정을 더해 산출했다. 실데이터가
쌓이면 위 4개 구성요소를 실측치로 교체한다.

### ARS (Answer-Readiness Score, 콘텐츠 대응력 점수 0~100)
"이 질문에 우리가 이미 얼마나 잘 답할 준비가 되어 있는가"를 나타낸다.

| 구성요소 | 가중치 | 설명 |
|---|---|---|
| 콘텐츠 보유 여부 (Exists) | 40% | 관련 블로그/쇼츠가 있으면 기본 40점 부여 |
| 콘텐츠 품질/최신성 (Quality) | 35% | 6개월 이내 업데이트, 실제 가격·후기 데이터 포함 여부 |
| 정보 확보 용이성 (Answerability) | 25% | 여행사 내부 자료로 즉시 답변 가능한 정도 |

가중치 표는 `data/score_config.csv` 에 있으며 Sheets의 `Score_Config` 탭으로
그대로 옮겨 담당자가 직접 조정할 수 있게 한다.

### Opportunity Score
```
Opportunity = GADS - ARS
```
값이 클수록 "수요는 큰데 콘텐츠가 없는" 우선순위 질문이다. 매주 이 값 기준으로
TOP 20을 추출해 콘텐츠 파이프라인에 투입한다.

## 4. Google Sheets 대시보드 구조

`data/master_questions.csv`, `data/score_config.csv` 를 Google Sheets로 임포트한 뒤
아래 6개 탭으로 구성한다. 각 탭의 수식/세팅은 `docs/SHEETS_SETUP.md` 참고.

| 탭 | 역할 |
|---|---|
| `Master_DB` | 마스터 질문 DB 본체 (master_questions.csv 임포트) |
| `Score_Config` | GADS/ARS 가중치 설정 (score_config.csv 임포트) |
| `Weekly_Trend_Log` | 매주 금요일 수집한 실제 관측 데이터(검색어, 상담 문의, 커뮤니티 언급) 적재 |
| `Weekly_TOP20` | Opportunity 기준 자동 추출된 이번 주 우선순위 20개 |
| `Content_Pipeline` | TOP20 → 블로그/쇼츠 기획-제작-발행 상태 트래킹 |
| `Dashboard` | 카테고리별 커버리지율, 연령대별 분포, 주간 트렌드 요약 차트 |

## 5. 매주 금요일 자동화

실제 "AI가 무엇을 질문받는지"를 직접 크롤링할 수 있는 공개 API는 없기 때문에,
자동화는 **반자동 수집 + 완전자동 스코어링/추출**의 2단 구조로 설계한다.

1. **수집 (반자동, 금요일 오전)**: 네이버 데이터랩 급상승 검색어, 구글 트렌드,
   실제 카카오톡/전화 상담 문의 로그, 골프 커뮤니티(세老카페 등) 신규 게시글을
   `Weekly_Trend_Log` 탭에 담당자가 기록하거나, Claude 세션에 WebSearch로
   보조 조사를 맡길 수 있다(6절 참고).
2. **스코어링/추출 (완전자동)**: `gas/WeeklyDigest.gs` 를 스프레드시트에 바인딩하고
   시간 기반 트리거(매주 금요일 09:00)를 걸면, Opportunity 상위 20개를
   `Weekly_TOP20` 탭에 자동 기록하고 담당자에게 이메일로 요약을 발송한다.
3. **전환**: `Weekly_TOP20` 의 각 행을 `Content_Pipeline` 탭으로 복사(수식 자동
   연결)해 블로그/쇼츠 제작 상태를 관리하고, 제작 완료 시 `Master_DB` 의
   `콘텐츠상태`를 "완료"로 갱신 → 다음 주 ARS/Opportunity 재계산에 반영된다.

## 6. Claude 세션 연동 (선택)

이 저장소 세션에는 매주 금요일 자동으로 깨어나 다음을 수행하는 Routine을
연결할 수 있다.
1. WebSearch로 이번 주 골프여행 관련 이슈(환율, 신규 항공노선, 특가 등) 조사
2. `Weekly_Trend_Log` / `Master_DB` 갱신이 필요한 항목 정리
3. `scripts/generate_questions.py` 로 신규 목적지/이슈 반영해 DB 갱신
4. 변경사항 커밋 & 푸시, 필요 시 TOP20 요약을 사용자에게 보고

원할 경우 `create_trigger` 로 "매주 금요일 09:00 KST"에 이 세션을 깨우는
Routine을 만들어드릴 수 있다. 자동으로 저장소에 커밋/푸시하는 반복 작업이므로
먼저 사용자 승인을 받는다.

## 7. 확장 로드맵

- **점수 실측화**: `gads_base` 를 실제 검색광고 API/데이터랩 API 연동으로 교체
- **DB 확장**: 목적지 풀·템플릿을 늘려 800~1000행까지 확장 (`generate_questions.py` 수정만으로 가능)
- **자동 매칭**: 발행된 블로그/쇼츠 URL을 `콘텐츠링크`에 자동 연결(제목 유사도 매칭)
- **성과 피드백 루프**: 발행 후 실제 조회수/문의전환을 ARS 재계산에 반영
