# MATCH-MOVE 골프 AI 질문 DB & 콘텐츠 갭 자동화 설계

40대~70대 한국 골퍼가 "국가→지역→골프장→패키지→가격→날씨→이동→숙박→식사→후기→
여행사 신뢰→안전→비교→구매" 여정에서 AI/검색엔진에 실제로 물어볼 법한 질문을
DB화하고, **골퍼가 이 질문들을 AI에 던졌을 때 더골프트렌드가 답변에
노출·인용되도록(GEO/AEO)** 콘텐츠 갭을 매주 찾아내며, 그 노출을 **문의·구매
전환**까지 연결·추적하는 시스템의 설계 문서다.

## 1. 전체 구조

```
[1] 마스터 질문 DB (data/master_questions.csv, 531행)
        │  질문 생성기: scripts/generate_questions.py
        ▼
[2] Google Sheets 마스터 시트 (CSV 임포트)
        │  GADS(수요)/ARS(콘텐츠 대응력)/AIVS(AI 노출) 점수 부여
        ▼
[3] 주간 트렌드 로그 + AIVS 체크 (매주 금요일, 수동+반자동 수집)
        │  Apps Script: gas/WeeklyDigest.gs
        ▼
[4] Weekly TOP20 신규제작 + GEO 재최적화 리스트 자동 추출
        ▼
[5] 콘텐츠 파이프라인 (블로그/쇼츠 기획→제작→발행→GEO최적화 트래킹)
        ▼
[6] 전환 트래킹 (문의·구매) → 다음 주 우선순위에 피드백
```

## 2. 질문 분류 체계 (14 카테고리)

요청하신 여정 순서를 그대로 L1 카테고리로 사용한다. 각 카테고리는
① 목적지(국가-지역)에 결합되는 **원형 템플릿**, ② 연령대(40/50/60/70대) 이슈가
강한 항목에 붙는 **연령대 템플릿**, ③ 목적지 무관 **일반/비교 템플릿** 세 종류로
질문을 생성한다.

| L1 카테고리 | 의미 | 대표 질문 예시 |
|---|---|---|
| 국가 | 국가 단위 관심/타당성 | "베트남 골프여행 요즘 갈만한가요?" |
| 지역 | 지역(다낭/세부 등) 단위 정보 | "다낭 골프투어 비수기는 언제예요?" |
| 골프장 | 코스 난이도/그린피/캐디 | "다낭 골프장 캐디 한국어 가능한가요?" |
| 패키지 | 일정 구성, 라운딩 횟수 | "3박5일 패키지에 라운딩 몇 회 포함되나요?" |
| 가격 | 총비용, 숨은 비용, 최저가 | "4박6일 골프여행 총 비용 얼마나 드나요?" |
| 날씨 | 시즌/체력 대비 날씨 | "우기에도 골프여행 가도 되나요?" |
| 이동 | 항공/공항-골프장 이동, 골프백 규정 | "장시간 비행 무릎 안 좋은데 괜찮을까요?" |
| 숙박 | 호텔 등급, 룸타입, 조식 | "골프텔이랑 리조트 중 뭐가 나아요?" |
| 식사 | 한식/현지식, 식단 조절 | "당뇨 있는데 현지식 괜찮을까요?" |
| 후기 | 실사용 후기, 신뢰도 검증 | "60대 이상 골퍼 후기 어디서 보나요?" |
| 여행사신뢰 | 여행사 검증, 계약/환불 | "여행사 사기 안 당하려면 뭘 확인하나요?" |
| 안전 | 보험, 지병, 응급상황 | "혈압약 챙겨서 가도 안전할까요?" |
| 비교 | 지역·상품·연령대 간 비교 | "베트남과 태국 중 어디가 나을까요?" |
| 구매 | 예약/할인/결제 전환 | "얼리버드 할인은 언제부터 시작하나요?" |

`data/master_questions.csv` 컬럼: `ID, L1_카테고리, 국가, 지역, 연령대, 질문,
GADS, ARS, Opportunity, 콘텐츠상태, 콘텐츠타입후보, 콘텐츠링크, AIVS, AIVS_확인일,
GEO최적화상태, 우선순위액션, 최종업데이트일, 담당자, 비고`

> **이 시스템의 최종 목적**: 이 질문들을 골퍼가 AI(챗GPT/퍼플렉시티/제미나이/네이버
> Cue 등)에 던졌을 때 **"더골프트렌드"가 답변에 노출·인용**되고, 그 노출이
> **문의(카톡/전화 상담)와 구매(예약)로 전환**되는 것이다. 콘텐츠를 "만들었는지"는
> 중간 지표일 뿐이고, 진짜 지표는 AI 노출(AIVS, 4절)과 전환(문의/구매, 4절)이다.

목적지 풀은 실제 한국 시니어 골프여행 수요가 있는 21개 지역(베트남 5·태국 4·
필리핀 3·중국 1·일본 3·캄보디아 1·말레이시아 1·국내 3)으로 구성했다. 카테고리별로
샘플링하는 목적지 수를 조절해 총량을 500~1000 범위(현재 531행) 안에서 통제한다.
`scripts/generate_questions.py` 의 `DEST_SAMPLE_SIZE`, 각 카테고리 템플릿 리스트를
늘리면 손쉽게 800~1000행까지 확장 가능하다.

## 3. GADS/ARS 점수체계

### GADS (Golf AI Demand Score, 수요 점수 0~100)
"이 질문을 실제 타겟 골퍼가 AI/검색에 물어볼 가능성"을 추정한다.

| 구성요소 | 가중치 | 설명 |
|---|---|---|
| 검색량 추정 (Search Volume Proxy) | 35% | 네이버 데이터랩·구글트렌드·검색광고 키워드플래너 상대값 |
| 시급성/시즌성 (Seasonality) | 20% | 현재 시점(성수기 임박, 환율 이슈 등)과 관련될수록 가중 |
| 구매전환 근접도 (Purchase Intent) | 30% | 가격/비교/구매 카테고리는 실제 상담·예약 직전 질문이라 가중 상향 |
| 연령대 적합성 (Age-fit 40~70) | 15% | 타겟 연령대가 실제로 던질 법한 질문일수록 가중 |

MVP 단계(현재 CSV)에서는 카테고리별 기준점수(`gads_base`, 예: 가격 90·비교 88·
날씨 60)에 목적지 인기도 보정과 질문별 미세 조정을 더해 산출했다. 실데이터가
쌓이면 위 4개 구성요소를 실측치로 교체한다.

### ARS (Answer-Readiness Score, 콘텐츠 대응력 점수 0~100)
"이 질문에 우리가 이미 얼마나 잘 답할 준비가 되어 있는가"를 나타낸다.

| 구성요소 | 가중치 | 설명 |
|---|---|---|
| 콘텐츠 보유 여부 (Exists) | 40% | 관련 블로그/쇼츠가 있으면 기본 40점 부여 |
| 콘텐츠 품질/최신성 (Quality) | 35% | 6개월 이내 업데이트, 실제 가격·후기 데이터 포함 여부 |
| 정보 확보 용이성 (Answerability) | 25% | 여행사 내부 자료로 즉시 답변 가능한 정도 |

가중치 표는 `data/score_config.csv` 에 있으며 Sheets의 `Score_Config` 탭으로
그대로 옮겨 담당자가 직접 조정할 수 있게 한다.

### Opportunity Score
```
Opportunity = GADS - ARS
```
값이 클수록 "수요는 큰데 콘텐츠가 없는" 우선순위 질문이다. 단, ARS는 어디까지나
**콘텐츠 존재 여부**만 본다 — 콘텐츠가 있어도 AI가 그걸 인용하지 않으면
사업 목표는 달성되지 않는다. 진짜 우선순위는 4절의 AIVS와 함께 판단한다.

## 4. GEO/AEO 전략 — AI 노출(AIVS) → 문의 → 구매

이 시스템의 존재 이유는 "질문 DB를 채우는 것"이 아니라 **AI 답변에서
더골프트렌드가 보이게 만들고, 그 노출을 상담·예약으로 전환하는 것**이다. 이를
위해 ARS(콘텐츠 대응력)와 별도로 AIVS를 추적하고, 콘텐츠별 전환 성과를 다시
우선순위에 반영한다.

### 4.1 AIVS (AI Visibility Score, AI 노출 점수 0~100)
"이 질문을 실제 AI 엔진에 물었을 때 더골프트렌드가 답변에 등장하는가"를 측정한다.

| 점수 | 의미 |
|---|---|
| 0 | 더골프트렌드 언급 없음 (경쟁사만 노출되거나 무관한 답변) |
| 40 | 브랜드명이 일반 언급 수준으로만 등장 (추천 리스트 중 하나) |
| 70 | 답변 내용의 근거로 간접 인용됨 (가격·후기 등 데이터가 출처 없이 반영) |
| 100 | 직접 인용 + 링크/출처로 명시적으로 노출 |

**측정 방법**: 현재 ChatGPT/Perplexity/Gemini/네이버 Cue 등 AI 엔진이 "특정
브랜드가 답변에 인용됐는지"를 알려주는 공식 API는 없다. 따라서 담당자(또는
Claude 세션)가 매주 금요일 TOP20 질문을 실제로 각 AI 엔진에 입력해 육안으로
확인하고 `Weekly_Trend_Log`(또는 `AIVS_Check` 탭, `docs/SHEETS_SETUP.md` 참고)에
점수를 기록한다. `Master_DB`의 `AIVS`, `AIVS_확인일` 컬럼에 반영한다.

### 4.2 우선순위 액션 매트릭스 (ARS × AIVS)

콘텐츠 유무(ARS)와 AI 노출(AIVS)을 교차하면 해야 할 일이 달라진다.

| | AIVS 낮음 (AI가 우리를 안 보여줌) | AIVS 높음 (AI가 우리를 보여줌) |
|---|---|---|
| **ARS 낮음 (콘텐츠 없음)** | 🔴 **신규 콘텐츠 제작** — 기존 Weekly TOP20 로직 | (드문 케이스, 무시) |
| **ARS 높음 (콘텐츠 있음)** | 🟠 **GEO 재최적화** — FAQ 스키마·직접답변 구조·최신화·브랜드명 명시 보강 | 🟢 **전환 최적화** — 문의/구매 CTA·상담 링크 강화 |

`우선순위액션` 컬럼(`Master_DB`)은 이 매트릭스에 따라 `신규제작대기` /
`GEO최적화필요` / `전환최적화` / `미확인` 값을 가진다. 생성 직후에는 AIVS를 알 수
없으므로 ARS 기준 1차값(`신규제작대기` 또는 `AI노출확인필요`)만 채워지고, 매주
AIVS 확인 후 `gas/WeeklyDigest.gs`가 재계산한다.

### 4.3 GEO 콘텐츠 체크리스트
AI가 실제로 인용하기 쉬운 형태로 만들기 위한 최소 기준. `Content_Pipeline`
탭에서 발행 전 체크한다.

- **직접답변 우선 구조**: 첫 문단에 질문에 대한 결론(가격, 기간, 가능여부)을
  바로 제시 — AI는 서두가 장황한 글보다 앞부분에서 답을 바로 찾는 글을 선호
- **FAQPage/Article 구조화 데이터(schema.org)** 삽입
- **구체적 수치/최신 데이터**: 실제 가격표, 최신 후기 날짜, 정확한 이동시간 등
  — 뭉뚱그린 표현보다 인용 가능한 "사실"이 AI 답변에 반영되기 쉬움
- **브랜드명 일관 노출**: 본문 중 "더골프트렌드"를 자연스럽게 반복 언급
- **신뢰 신호**: 여행사 등록번호, 실제 후기, 저자/전문성 표기 (E-E-A-T)
- **6개월 이내 최신화** — AI 검색은 최신 콘텐츠를 우선 인용하는 경향이 큼

### 4.4 전환 퍼널 트래킹 (문의·구매)
AI 노출이 실제 매출로 이어지는지 측정하지 않으면 우선순위가 허상이 된다.

1. 콘텐츠(블로그/쇼츠)마다 **고유 문의 링크**(카카오채널 플친 링크 + UTM,
   전화번호 대신 콘텐츠별 트래킹 가능한 채널 링크)를 발급해 `Content_Pipeline`
   의 `문의링크` 컬럼에 기록
2. 주간 문의/구매 건수를 `문의수`, `구매수`, `전환율` 컬럼에 집계
   (카카오톡 채널 관리자센터 또는 CRM에서 UTM별 집계)
3. 전환율이 높은 카테고리(예: 가격/비교/구매)는 GADS 가중치의
   "구매전환 근접도" 항목을 상향 조정해 다음 주기 우선순위에 반영 —
   즉 이 시스템은 고정 점수가 아니라 **실제 전환 데이터로 자기보정**한다

## 5. Google Sheets 대시보드 구조

`data/master_questions.csv`, `data/score_config.csv` 를 Google Sheets로 임포트한 뒤
아래 7개 탭으로 구성한다. 각 탭의 수식/세팅은 `docs/SHEETS_SETUP.md` 참고.

| 탭 | 역할 |
|---|---|
| `Master_DB` | 마스터 질문 DB 본체 (master_questions.csv 임포트, AIVS 포함) |
| `Score_Config` | GADS/ARS/AIVS 가중치·정의 (score_config.csv 임포트) |
| `Weekly_Trend_Log` | 매주 금요일 수집한 실제 관측 데이터(검색어, 상담 문의, 커뮤니티 언급) 적재 |
| `AIVS_Check` | 매주 TOP 질문을 AI 엔진별로 직접 확인한 노출 여부 기록 |
| `Weekly_TOP20` | 신규제작 우선순위 20개(ARS 낮음) + GEO 재최적화 대상(ARS 높음·AIVS 낮음) |
| `Content_Pipeline` | 기획-제작-발행-GEO최적화 + 문의수/구매수/전환율 트래킹 |
| `Dashboard` | 카테고리별 커버리지율·AI노출율, 연령대별 분포, 문의/구매 전환 추이 |

## 6. 매주 금요일 자동화

실제 "AI가 무엇을 질문받는지"를 직접 크롤링할 수 있는 공개 API는 없기 때문에,
자동화는 **반자동 수집(트렌드+AIVS 체크) + 완전자동 스코어링/추출**의 2단
구조로 설계한다.

1. **수집 (반자동, 금요일 오전)**: 네이버 데이터랩 급상승 검색어, 구글 트렌드,
   실제 카카오톡/전화 상담 문의 로그, 골프 커뮤니티(시니어 카페 등) 신규 게시글을
   `Weekly_Trend_Log` 탭에 기록한다. 동시에 지난주 TOP20/기존 상위 콘텐츠
   질문들을 ChatGPT/Perplexity/Gemini/네이버 Cue에 직접 입력해 AIVS를
   확인하고 `AIVS_Check` 탭에 기록한다(4.1절). Claude 세션에 WebSearch로
   보조 조사를 맡길 수 있다(7절 참고).
2. **스코어링/추출 (완전자동)**: `gas/WeeklyDigest.gs` 를 스프레드시트에 바인딩하고
   시간 기반 트리거(매주 금요일 09:00)를 걸면, ① ARS 낮은 질문 중 Opportunity
   상위 20개(신규제작 대상)와 ② ARS 높지만 AIVS 낮은 질문(GEO 재최적화 대상)을
   `Weekly_TOP20` 탭에 자동 기록하고 담당자에게 이메일로 요약을 발송한다.
3. **전환**: `Weekly_TOP20` 의 각 행을 `Content_Pipeline` 탭으로 옮겨 제작/재최적화
   상태를 관리하고, 발행·수정 완료 시 `Master_DB` 의 `콘텐츠상태`·`GEO최적화상태`를
   갱신한다. 이후 실제 AIVS가 오르는지, 문의·구매로 이어지는지(4.4절)를
   다음 주 사이클에서 다시 측정해 우선순위를 보정한다.

## 7. Claude 세션 연동 (선택)

이 저장소 세션에는 매주 금요일 자동으로 깨어나 다음을 수행하는 Routine을
연결할 수 있다.
1. WebSearch로 이번 주 골프여행 관련 이슈(환율, 신규 항공노선, 특가 등) 조사
2. `Weekly_Trend_Log` / `Master_DB` 갱신이 필요한 항목 정리
3. TOP20 질문 일부를 실제 AI 엔진에 물어 더골프트렌드 노출 여부 샘플 확인 →
   `AIVS_Check` 업데이트 제안 (완전 자동 크롤링은 불가, 참고용 샘플 체크)
4. `scripts/generate_questions.py` 로 신규 목적지/이슈 반영해 DB 갱신
5. 변경사항 커밋 & 푸시, 필요 시 TOP20/GEO 재최적화 요약을 사용자에게 보고

원할 경우 `create_trigger` 로 "매주 금요일 09:00 KST"에 이 세션을 깨우는
Routine을 만들어드릴 수 있다. 자동으로 저장소에 커밋/푸시하는 반복 작업이므로
먼저 사용자 승인을 받는다.

## 8. 확장 로드맵

- **점수 실측화**: `gads_base` 를 실제 검색광고 API/데이터랩 API 연동으로 교체
- **DB 확장**: 목적지 풀·템플릿을 늘려 800~1000행까지 확장 (`generate_questions.py` 수정만으로 가능)
- **AIVS 반자동화**: Perplexity API 등 답변 인용 확인이 가능한 API가 열리면
  `AIVS_Check` 수집을 자동 호출로 대체
- **자동 매칭**: 발행된 블로그/쇼츠 URL을 `콘텐츠링크`에 자동 연결(제목 유사도 매칭)
- **성과 피드백 루프**: 문의/구매 전환 데이터를 GADS 가중치·우선순위에 자동 반영
