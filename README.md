# MATCH-MOVE

한국 공항 → 동아시아·동남아시아 공항의 비행을 **지구본 위성지도** 위에서 보여주고,
도착지로 카메라가 줌인하며 끝나는 장면을 **MP4 영상 / PNG 이미지**로 저장하는 웹 도구입니다.

## 실행 (내 PC에서)

> `localhost:5173`은 **내 PC에서 서버를 직접 실행해야** 열립니다. (클라우드 세션 안의 서버에는 PC 브라우저가 접속할 수 없습니다.)

1. [Node.js](https://nodejs.org) 20 이상 설치 (`node -v`로 확인)
2. 터미널에서:
   ```bash
   git clone https://github.com/kundo-code/MATCH-MOVE.git
   cd MATCH-MOVE
   git checkout claude/gallant-lamport-mdgiuo   # main에 병합되기 전이라면
   npm install
   npm run dev
   ```
3. 브라우저에서 http://localhost:5173 접속. (터미널을 닫으면 서버도 종료됩니다.)

### 더블클릭으로 실행

터미널 명령 없이 프로젝트 폴더의 파일을 더블클릭해도 실행됩니다. (Node.js는 먼저 설치되어 있어야 합니다.)

- **Mac**: `start.command` 더블클릭 — 열리지 않으면 터미널에서 한 번만 `chmod +x start.command` 실행
- **Windows**: `start.bat` 더블클릭

실행하면 최신 코드를 받고(`git pull`), 필요한 패키지를 설치한 뒤 서버를 켜고 브라우저를 자동으로 엽니다. 종료하려면 열린 창을 닫으세요.

정적 파일로 배포하려면 `npm run build` 후 `dist/` 폴더를 웹서버에 올립니다.
Chrome / Edge 최신 버전을 권장합니다. (MP4 인코딩은 브라우저 WebCodecs를 사용하므로 별도 서버가 필요 없습니다.)

## 사용방법

좌측 설정은 번호가 붙은 접이식 항목(1 항공사 ~ 7 출력 설정)으로 되어 있고, 처음에는 **출발 공항·도착 공항만 펼쳐져** 있습니다. 하위 항목은 라인으로 묶여 있고, 도착 공항은 **권역 → 국가 → 공항** 순서로 선택해야 다음 단계가 활성화되며 공항은 가나다순으로 전부 한 번에 보입니다. 항공사는 대한민국/일본·중화권/동남아시아로 묶여 있습니다. 각 항목 오른쪽에 현재 선택값이 요약되고, 상단의 *펼치기/접기* 버튼과 항목별 접기 상태가 기억되며, *이미지/영상 저장* 버튼은 항상 하단에 고정됩니다.

1. **항공사** 선택 — 기체 색과 경로선 색이 바뀝니다.
2. **출발 공항** 선택 — 기본값은 인천국제공항 제1터미널.
3. **도착 공항** 선택 — ① 권역(동아시아/동남아시아) → ② 국가 → ③ 공항 순서로 고릅니다. 공항 목록 위 검색창에서 공항명·도시·IATA 코드(예: 푸켓, HKT)로 좁힐 수 있습니다.
4. **비행시간** — 자동 추정값이 표시됩니다. 실제 시간표 값이 있으면 가는 편/오는 편 칸에 분 단위로 입력.
5. **표시 옵션**
   - **출발 지점 / 도착 지점** 각각 *붉은 타겟 원형*과 *정보박스*를 따로 켜고 끌 수 있고, 각각의 **크기(40~250%)** 도 슬라이더로 조절합니다. 항공사·노선 정보 박스는 우측 상단에 표시되고(영문 약어 아래 국문 약칭), **상단 항공 정보 / 하단 정보 카드** 도 박스 크기와 글자 크기를 각각 조절할 수 있습니다. (타겟은 기체 아래에 그려져 비행기가 항상 위에 보입니다.)
   - **비행기 크기** — 멀리 축소된 장면에서도 화면 너비 대비 일정한 비율로 보이며, 슬라이더로 50~300% 조절합니다.
   - **지도 시점**(5번 항목) — **시작 화면 / 도착 화면** 탭을 고른 뒤 확대/축소(40~500%)·회전·기울기를 조절합니다. 탭을 고르면 미리보기가 그 시점으로 이동하고, 애니메이션은 시작 화면에서 도착 화면으로 자연스럽게 이어집니다. 미리보기에서는 **드래그 = 지도 이동**, **Shift+드래그 또는 우클릭 드래그 = 회전·기울기**, **휠 = 확대/축소**, **더블클릭 = 편집 중인 화면 초기화**. 모든 조작은 부드럽게 따라옵니다.
   - **입체감·조명** — 측면 조명, 지형 **노멀맵**(전 지구 4096×2048 + 공항 주변은 고도 타일로 생성), 바다 윤기, 비행기 금속 반사·명암, 비행기 그림자. 강도 슬라이더(기본 70%, 0%=평평한 조명)와 그림자 켜기·끄기.
   - 지구 전체 화면에서 시작 / 국경선 / 국가명 / 구름 / 고해상도 타일 켜기·끄기.
6. **출력 설정** — 화면 비율(16:9 / 9:16 / 1:1), 해상도(FHD·QHD·4K), 프레임(30/60fps), 영상 길이(8~40초, 기본 8초), 목표 용량(기본 50MB).
7. 오른쪽 미리보기에서 재생·일시정지·타임라인 이동으로 장면 확인. 타임라인 옆 **정보 카드** 스위치로 좌측 하단 정보 카드를 켜고 끌 수 있으며 저장되는 영상·이미지에도 그대로 반영됩니다.
8. **이미지 저장(PNG)** 은 현재 미리보기 시점의 장면을, **영상 저장(MP4)** 은 처음부터 끝까지 렌더링해 저장합니다.
   영상 저장 중에는 진행률이 표시되고 *취소* 할 수 있으며, 탭을 닫거나 다른 탭으로 전환하지 말고 기다려 주세요.

| 비율 | 출력 크기 (FHD / QHD / 4K) | 용도 |
| --- | --- | --- |
| 16:9 | 1920×1080 / 2560×1440 / 3840×2160 | 유튜브, PC |
| 9:16 | 1080×1920 / 1440×2560 / 2160×3840 | 쇼츠, 릴스, 틱톡 |
| 1:1 | 1080² / 1440² / 2160² | 인스타 피드 |

## 기능

| 구분 | 내용 |
| --- | --- |
| 항공사 | 대한항공·아시아나·제주항공 등 25개. 선택한 항공사의 도색(동체·꼬리 색)과 경로선 색이 적용된 3D 기체가 날아갑니다 |
| 출발지 | 한국 국제공항 8곳(인천 T1/T2, 김포, 김해, 제주, 대구, 청주, 무안, 양양). 기본값 **인천국제공항 제1터미널** |
| 도착지 | 동아시아(일본·중국·홍콩·마카오·대만·몽골), 동남아시아(베트남·태국·필리핀·싱가포르·말레이시아·인도네시아·캄보디아·라오스·미얀마·브루나이·동티모르) 553개 공항(전부 한국어 공항명 지원), 권역→국가→공항 순 선택·검색 |
| 항상 표시되는 정보 | 항공사, 출발·도착 국가명/공항명(지점에서 뻗은 선 끝 정보박스), 비행경로, 하단 카드의 비행거리와 **가는 편·오는 편 소요시간** |
| 연출 | 지구 전체 → 두 공항이 한 화면에 들어오는 샷(확대/축소 가능) → 출발 지점에서 곧바로 일정한 각도로 상승 → 정점에서 수평 → 완만한 글라이드 접근 → 접지(랜딩기어) → 도착 공항 지점에서 정지, 줌인은 **출발부터 도착까지 전 구간**에 걸쳐 완만하게 진행되며, 도착 직전까지 비행기·도착지·정보박스·지나온 경로 일부가 항상 함께 보입니다(상단 박스·하단 카드와도 겹치지 않음). 동남아시아는 지구 윤곽이 보이는 넓은 화면(카메라 거리 ≈ 1.3~1.6, 가까운 나라일수록 조금 더 확대)에서 시작하며, '시작 화면' 옵션(자동/경로에 딱 맞춤/항상 넓게)으로 바꿀 수 있습니다. 도착 정지 시점은 영상 끝 5% 전입니다. 도착지가 한국 기준 서쪽이면 비행기가 화면 우상단→좌하단, 동쪽이면 좌상단→우하단으로 들어와 착륙합니다 |
| 경로 | 출발~도착을 잇는 지표면 직선(대권) 빨간 점선(투명도 70%, 육지·바다 모두 끊김 없음), 항공사 색 궤적선·귀환 경로(흰 점선) |
| 기체 | 항공사별 도색(동체·꼬리·엔진·윙렛)이 입혀진 3D 여객기. 대한항공·아시아나·제주항공·말레이시아항공·바틱에어는 사진을 참고한 개별 디자인 |
| 출력 | PNG(현재 장면), MP4(H.264, 목표 용량 기본 50MB에 맞춰 비트레이트 자동 계산) |

### 비행시간
순항속도 800 km/h, 서→동 제트기류 ±60 km/h, 이·착륙/지상 이동 45분을 반영한 **추정치**입니다.
동행(가는 편)이 서행(오는 편)보다 짧게 나옵니다. 실제 시간표 값이 있으면 UI에서 분 단위로 직접 입력할 수 있습니다.

### MP4 출력
- 프레임을 하나씩 렌더링해 인코딩하므로 PC 성능과 무관하게 프레임 누락이 없습니다.
- 목표 용량(MB)에서 비트레이트를 역산(CBR)하므로 15초 영상이면 약 25 Mbps로, 1080p/4K 모두 50MB 안팎에서 가장 높은 화질이 나옵니다.
- 고품질 렌더링(슈퍼샘플링)을 켜면 FHD·QHD는 더 큰 해상도로 그린 뒤 축소해 가장자리가 부드러워집니다. (4K는 제외)
- 비율 16:9·9:16·1:1, 해상도 FHD·QHD·4K, 30·60fps.

## 구조

```
src/
  main.js        UI·상태·미리보기 루프·출력 오케스트레이션
  globe.js       Three.js 지구본, 국경(GeoJSON), 경로, 기체, 카메라 타임라인
  satellite.js   공항 주변 고해상도 위성 타일(Esri World Imagery) 패치
  hud.js         공항/국가 라벨·정보 카드 (2D 캔버스, 미리보기와 영상에 동일 적용)
  flight.js      대권 경로, 거리·방위각, 비행시간 추정
  exporter.js    WebCodecs + mp4-muxer MP4, PNG
  data/airlines.js
scripts/build-data.mjs   OurAirports·Natural Earth → public/data/*.json  (npm run data)
```

## 다른 대륙으로 확장
`scripts/build-data.mjs`의 `REGIONS`에 권역과 국가 코드를 추가하고 `COUNTRY_KO/EN`에 국가명을 넣은 뒤 `npm run data`를 실행하면
도착지 권역 버튼과 공항 목록에 자동 반영됩니다. 한국어 공항명은 `scripts/airport-names-ko.mjs`(주요 공항), `scripts/airport-names-ko-extra.mjs`(소규모 공항)에 추가합니다(없으면 영문명 표시).

## 데이터 출처 / 라이선스 유의
- 지구 텍스처: NASA Blue Marble (three-globe 예제 이미지)
- 국경·국가명: Natural Earth (퍼블릭 도메인)
- 공항: OurAirports (퍼블릭 도메인)
- 고해상도 타일: Esri World Imagery. 영상에 출처가 자동 표기됩니다. **상업적 배포 영상**에 쓸 경우 Esri 이용약관을 확인하세요. 옵션을 끄면 NASA 텍스처만 사용합니다.
- 항공사 도색은 단순화한 색 표현이며 실제 로고·기체 디자인이 아닙니다.
